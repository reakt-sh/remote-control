
Train (Clock)               :  100          101         102            103          104         105
Remote(Clock)               : 5000         5001        5002           5003         5004        5005

   clock_offset = remote_timestamp - train_timestamp
                = 5000 - 100
                = 4900


Example:
   remote_timestamp = 5003 (when the remote sends a message)
   train_timestamp = 105 (when the train receives the message)

   adjusted_remote_timestamp = remote_timestamp - clock_offset
                             = 5003 - 4900
                             = 103

   latency = train_timestamp - adjusted_remote_timestamp
           = 105 - 103
           = 2

receiving:
------------------------------------
current_timestamp = 220
{
   train_timestamp = 100
   remote_timestamp = 5064
}

RTT = current_timestamp - train_timestamp
    = 220 - 100
    = 120


clock_offset = remote_timestamp - (train_timestamp + RTT / 2)
             = 5064 - (100 + 120 / 2)
             = 5064 - (100 + 60)
             = 5064 - 160
             = 4904

Here we have an ERROR of 4ms
